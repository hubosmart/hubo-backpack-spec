# Hubo-Tack PCB Layout 通用规范（SPEC-005 公开版 V0.12）

> **制定基准：** 第十章规定全部走线的基础规则（拐角、线宽线距、过孔、焊盘出线、电源线宽）；其余各章按信号等级规定 USB、SPI、MIPI、SDIO、时钟与射频的走线、过孔与间距要求；芯片厂的附加要求列于附录，按芯片分列。数值取自芯片厂硬件设计指南、PCB 厂教程与行业应用笔记（2026-10-08 检索并核对原文），各来源数值不一致之处的取舍见附录 C。
>
> 本文是内部规范 SPEC-005 V0.12（草案）的公开版，章节与条款编号保持原样；与公开范围无关的附录与内部流程不随公开版发布，对应编号处标注“（本公开版不含）”。本规范仍为草案，数值可能随实测和审定修订。

## 一、适用范围与信号分级

### 1.1 适用范围

本规范适用于 Hubo-Tack 相关的 PCB（主板、30-Pin 背包板等），不限 EDA 工具。Hubo-Tack 30-Pin 背包另须满足 [SPEC-003](./30pin-backpack-spec.md)；两者冲突时以 SPEC-003 为准。

### 1.2 信号分级

规则由信号的速率与边沿决定，与所用芯片品牌无关。**第十章基础走线规则适用于全部网络**；每块板的设计文档另须列出**本板涉及的等级**，按表执行对应章节。

| 等级 | 典型信号 | 执行章节 |
|---|---|---|
| L 低速 | I2C、UART、GPIO、LED 数据、≤ 20 MHz 的 SPI | 仅第十章 |
| U1 USB 全速 | USB 2.0 全速 12 Mbps（如 S3 USB-OTG 全速） | 二、3.1 |
| U2 USB 高速 | USB 2.0 高速 480 Mbps（如 ESP32-P4 USB 高速口） | 二、3.2 |
| S 高速 SPI | > 20 MHz 的 SPI／QSPI／OPI，含 Flash、PSRAM | 二、四 |
| M MIPI | MIPI CSI／DSI | 二、五 |
| D SDIO | SDIO、SD 卡 4 线 | 二、六 |
| C 时钟 | 无源晶振、有源晶振输出 | 七 |
| R 射频 | 天线馈线、射频模组输出 | 八 |

20 MHz 分界为本规范取值（低于此频率时走线长度相对上升沿可忽略，Altium《Is There an SPI Trace Impedance Requirement?》的判断方法），不是行业标准。

### 1.3 芯片附加要求

芯片厂硬件设计指南中的要求严于本规范时，以芯片厂为准。已整理的芯片见附录 A、B、D；**使用未整理的芯片前，须先读该芯片的硬件设计指南并增补附录**，未增补前不得开始布线。

## 二、通用规则（U1 以外的高速等级）

| 条款 | 要求 | 来源 |
|---|---|---|
| 2.1 参考平面 | 高速线正下方相邻层为完整 GND，不跨分割缝、不跨平面边界 | 乐鑫 ESP32-P4／S3 硬件设计指南（USB、MIPI、SDIO 节）；SPEC-003 6.2.3 |
| 2.2 换层回流 | 尽量不换层；必须换层时每次在信号过孔旁 **≤ 1 mm** 加回流地孔，差分对加一对 | 乐鑫（“每次打孔换层的地方加一对地孔回流”）；SPEC-003 6.2.5 |
| 2.3 差分过孔对称 | 差分对两线过孔数相同、位置对称 | TI SPRAAR7J；嘉立创 Wiki |
| 2.4 拐角 | 不得有 90° 拐角，用 45°（内角 135°）或圆弧 | 乐鑫射频节；嘉立创；Altium |
| 2.5 间距 | 高速线与其他信号中心距 **≥ 3W**（W 为线宽），推荐 5W；不得与时钟、开关电源走线长距离平行 | 嘉立创 3W；乐鑫 MIPI 节 3W；TI 5W。取舍见附录 C |
| 2.6 测试点 | U2、M 等级差分线上不放测试点，不留分支 | TI SPRAAR7J（高速差分测试点 0 个） |
| 2.7 等长绕线 | 蛇形线只加在较短一线，靠近失配处（过孔、拐弯、引脚附近）；蛇形段间距 ≥ 3W | TI SPRAAR7J；JLCPCB 博客 |
| 2.8 过孔残桩 | **≤ 480 Mbps 等级（U1、U2、L、S、D）** 用 1.6 mm 通孔即可，不限残桩、不背钻。**Gbps 级（如 M MIPI）整对线不换层**，4 层板上则不存在残桩；必须换层时残桩 **≤ 15 mil**，更长须背钻或改走另一面 | TI SPRAAR7J（15 mil 限值针对 Gbps 级信号） |
| 2.9 包地地孔 | 高速差分线的包地铜（两侧及对间地铜）须**沿全长**用地孔接参考地平面，**禁止只在两端接地**；放不下地孔的窄包地铜应删除，改用 ≥ 3W 间距。地孔间距按 λ/20 取（λ 按 2.5 倍比特率、FR-4 有效介电常数 3.5～4.1 计算），受空间限制时不得大于 λ/10。常用取值：MIPI（≤ 1 Gbps/lane）**≤ 3 mm**；HDMI TMDS（≤ 1080p）**≤ 4 mm**；USB 2.0 HS **≤ 6 mm**；速率更高时按公式重算并写入设计文档。芯片扇出区、连接器与 ESD 焊盘区可豁免，豁免段在设计文档列出 | EDN Hageman《Via Spacing on High-Performance PCBs》（λ/20，引 Ott、Vizmuller）；ProtoExpress、AtlasPCB（λ/20～λ/10）；Bogatin & Simonovich《Guard Traces: Love Them or Leave Them?》（只在两端接地会形成谐振腔，串扰反增）；Panox MIPI DSI 指南（≤ 200 mil，单源）。芯片厂（TI、Renesas、乐鑫）文档无此数值，取舍见附录 C |
| 2.10 连接器引脚分配 | 高速差分对在连接器上按“**GND — 差分对 — GND**”排列，每对左右各有一根地针；从芯片到连接器的扇出用平滑圆弧、P/N 保持对称，P/N 非耦合段尽量短。2.54 mm 排针上 P/N 分列两排的“八爪鱼”扇出（P 接一列、N 接另一列、对间夹地针）只用于调试排针，量产不建议；排针对阻抗与残桩的影响数据未找到，HDMI 风险高 | Samtec FAQ（信号:地 1:1 通常最优，对间加地屏蔽有益）；树莓派 CSI 22 针座每对线间夹一根地（Arducam 整理的引脚定义，二手）。为建议级，FPC 座引脚定义以屏厂或模组为准 |
| 2.11 内层走低速信号 | 4 层板的电源层（L3，含“电源块＋GND 填充”的混合层）**允许走少量低速信号**（UART、I2C、GPIO、≤ 8 MHz SPI），须同时满足：① RF 与晶振下方有完整 GND；② 信号线相邻的参考层完整、**不跨分割缝**，必须跨缝时在跨越处加缝合电容；③ 信号线两侧有地铜并沿线打地孔；④ 记录该信号的**实际最近参考层**（L3 与 L4 间距若小于与 L2 间距，则最近的是 L4）。**高速信号（≥ 480 Mbps 等级）不走电源层、不以电源平面为参考**，不得已时加缝合电容；GNSS 等敏感模块下方，顶层与第二层须铺地且不走信号线 | Espressif ESP 硬件设计指南 PCB 布局章（L3 “route power traces and a few signal traces ... provided that there is a complete GND plane under the RF and crystal”；ESP32-S31 “Signal traces are allowed”；UART “surrounded by ground copper and ground vias”）；TI SLLA414 §3.4、SCAA082A §2.3（不跨缝，必须跨缝加缝合电容）；ST AN4488 §8.4（参考 PWR 须加 10 nF 缝合电容）；u-blox MAX-M10S 集成手册 §4.4（模块下方顶层与第二层铺地，不走信号线）；Altium 博客（印证：UART 可跨缝，PWR 层不宜当通用信号层） |

**20H 规则（电源层内缩 20 倍介质厚度）不作要求。** 其 EMI 抑制效果在现代多层板上不稳定（IEEE《Effects of 20-H Rule and Shielding Vias on EMI Radiation》；Clemson CVEL 研究）。板边 GND 缝合过孔按 SPEC-003 6.2.7，与 20H 无关。

## 三、USB 2.0

### 3.1 全速（U1）

| 条款 | 要求 | 来源 |
|---|---|---|
| 3.1.1 走线 | D+／D− 按差分对平行走线，尽量短；**不要求阻抗控制与等长** | 本规范取值：12 Mbps 边沿慢，板内短线影响可忽略（未查到一手来源） |

### 3.2 高速（U2）

| 条款 | 要求 | 来源 |
|---|---|---|
| 3.2.1 阻抗 | 90 Ω 差分 ±10%，线宽线距按 SPEC-003 6.5 | 乐鑫 P4／S3；嘉立创 |
| 3.2.2 器件 | 线上预留的电阻、电容靠近芯片；ESD／TVS 靠近连接器 | 乐鑫；嘉立创《USB模块》；TI |
| 3.2.3 包地 | 差分对两侧包地 | 乐鑫 |
| 3.2.4 换层 | 尽量不换层，**每线过孔 ≤ 2 个**，每次换层按 2.2 加一对地孔 | 乐鑫（尽量减少）；TI（USB 2.0 每线 ≤ 4 个）。≤ 2 为本规范取值 |

| 3.2.8 离边 | 建议距板边、铺铜边缘 ≥ 90 mil（2.29 mm） | TI SPRAAR7J（差分过孔距参考平面边缘 ≥ 90 mil）；二手资料。单源，未核实，不作硬性要求 |

## 七、时钟与晶振（C）

| 条款 | 要求 | 来源 |
|---|---|---|
| 7.1 过孔 | 晶振时钟走线**不得打过孔** | 乐鑫 P4／S3 |
| 7.2 包地 | 时钟走线用地包围，周围密集地孔；两侧电源过孔远离时钟线 | 乐鑫 P4／S3 |
| 7.3 器件位置 | 串联器件靠近芯片；对地调节电容靠近晶振两侧，不直接接在串联器件上 | 乐鑫 P4／S3 |
| 7.4 下方 | 晶振下方不走高频信号，最好不走任何信号 | 乐鑫 P4／S3 |
| 7.5 地平面 | 晶振与芯片之间为完整地平面 | 乐鑫 P4／S3 |
| 7.6 磁性器件 | 晶振周围不放大电感等磁性器件 | 乐鑫 P4／S3 |
| 7.7 距离 | 晶振到芯片时钟管脚的最小距离按芯片附录（P4 ≥ 4.5 mm，S3 ≥ 2.0 mm） | 乐鑫 |

晶振厂 ECS 主张“晶振正下方不铺地”，与乐鑫“晶振和芯片之间有完整地平面”相反；用乐鑫芯片时**以乐鑫为准**，不采用 ECS 的做法。

## 九、检查

KiCad 工程用 hubo-backpack-skill 中 `hubo-kicad` 技能的脚本检查，结果写入设计文档：

| 检查项 | 工具 | 对应条款 |
|---|---|---|
| 差分线宽、线距、出线区收窄 | `impedance_check.py` | 3.2.1、5.1 |

| 线宽线距、焊盘到线、孔径与焊环、孔到孔、板边、丝印、电源网络最小线宽 | KiCad DRC（`power_rules.py` 按工程配置生成规则） | 10.2～10.5、10.8、10.9 |
| 不同元件焊盘重叠或间距 < 0.1 mm（含同网络） | `route_check.py` 第 3 项（DRC 不查同网络焊盘） | 10.12 |
| 包地铜沿线地孔间距 | `fence_check.py` | 2.9 |
| 全板直角与锐角、盘中孔 | `route_check.py` | 10.1、10.7 |

脚本不能判断的项（器件摆放顺序、包地是否到位、拓扑、焊盘下参考层挖空、电源铜皮是否替代细线）在 KiCad 界面中人工核对。

## 十、基础走线规则（全部网络）

本章适用于全部网络（含 L 级）。工艺数值取自嘉立创《工艺参数》页（jlc.com/portal/vtechnology.html，2026-10-09 核对原文）；“推荐值”严于工艺下限，低于推荐值的走线须在设计文档中列出位置与理由。

| 条款 | 要求 | 来源 |
|---|---|---|
| 10.1 拐角 | 不得有 90° 直角与锐角拐角，用 45° 或圆弧；走线与焊盘、走线与走线之间不得形成锐角夹缝。拐角点落在同网络焊盘或过孔铜内的不计（拐角被铜覆盖） | 锐角：蚀刻残液（酸角）风险，工艺通识；90°：本规范统一要求（高速线另有电气理由，见 2.4） |
| 10.2 线宽线距 | **推荐 ≥ 5／5 mil**（0.127 mm）；工艺下限 1 oz 双面板 4／4 mil、多层板 3.5／3.5 mil；多层板低于 3.5 mil 加收 20% | 嘉立创工艺参数；嘉立创《PCB附加收费一览表》 |
| 10.3 焊盘到线 | 焊盘边到线边 ≥ 0.1 mm | 嘉立创工艺参数 |
| 10.4 过孔 | 常规取孔径 0.3 mm／外径 0.6 mm（本规范取值）；孔径 ≥ 0.3 mm、外径 ≥ 0.4 mm 且比孔径大 ≥ 0.15 mm（常规最小 0.3／0.45 mm）；孔径 < 0.3 mm 且外径 ≤ 0.4 mm 的过孔嘉立创要加收费用（TG155 板材＋四线低阻全测），确需更小时在设计文档写明并接受加价；过孔孔边到孔边 ≥ 0.2 mm；插件孔孔边到孔边 ≥ 0.45 mm，多层板焊环 ≥ 0.2 mm | 嘉立创工艺参数；嘉立创《PCB 附加收费一览表》；工艺下限 0.15／0.25 mm 为“非常规，费用高” |

| 10.7 盘中孔 | 贴片焊盘上不打过孔，**信号孔一律不得打在焊盘上**；确需打孔时下单选“盘中孔”（树脂塞孔＋电镀盖帽）并在设计文档说明。**例外：**芯片底部散热焊盘上与焊盘同网络、孔径 ≤ 0.3 mm 的散热／接地孔可不塞孔、不按盘中孔工艺下单；优先做进封装，钢网开窗避开孔位 | 嘉立创工艺参数（盘中孔为单独工艺）；未塞孔的过孔会吸走焊锡；TI SLUA271C《QFN and SON PCB Attachment》（孔越小吸锡越少，不塞孔亦可重复焊接） |

| 10.13 LDO 输出电容 | 手册靠输出电容 ESR 做环路补偿的经典 1117 类 LDO（AMS1117、LM1117、LD1117 等），**不得只放 MLCC 而不留钽／电解位**：输出端须放（或至少预留可 DNP 的）**22 µF 固态钽**（AMS1117 手册原文）；TI LM1117 要求 ESR 0.3～22 Ω。打样后用示波器测空载与满载瞬态，有振荡或跌落再焊钽。选用手册明确“陶瓷稳定”的 LDO（如 TPS7A20／TPS7A2033，Cout 1～200 µF）则按其手册，不受此限。输出钽并联的目的是 ESR 稳定，**不是滤纹波** | AMS1117 手册 ds1117（advanced-monolithic.com，Application Hints“Stability”：22 µF solid tantalum on the output ensures stability）；TI LM1117 手册 §9.2.2.1.3（最小 10 µF 钽，ESR 0.3～22 Ω）；TI AN-1482（ESR 零点与相位裕度：带零点约 68°，无零点约 11°，MLCC 不适用）；乐鑫 ESP32-DevKitC V4 原理图输出 22 µF；社区：EEVblog 2025-01“全 MLCC 振荡，换铝电解后稳定”（单源，无波形）。AMS1117 手册未给 ESR 数值范围 |
| 10.14 改动后复核 | 换封装、移动元件或改线后，**必须重导 Gerber 后再做审计与检查**（用改动前的 Gerber 会得出过时结论），并复查：拐角（10.1，移动元件常把原 45° 线拖成折返锐角）、焊盘重叠（10.12）、板边（10.5）、盘中孔（10.7）、DRC 详细模式（嘉立创EDA 简略模式返回空）。库封装可能自带板框层线（如 USB-C 封装），会进 Gerber 变成切割线，须从封装里删除 | — |
